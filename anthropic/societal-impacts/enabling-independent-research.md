*今年早些时候，我们进行了一项试点，让外部研究人员能够访问汇总的、真实的Claude使用数据。三个研究小组为我们的隐私保护分析工具 Anthropic Insights 设计了自己的研究；我们代表他们进行数据收集，他们进行了自己的独立分析。在这篇文章中，我们分享了这些研究的高水平结果以及我们在运行该试点项目中学到的知识。我们还提供 [意向表达表](https://docs.google.com/forms/d/e/1FAIpQLScujFA2mJXnLhrvE7wazD7drfHlfRmfnrjhMZRpeIFW_b6I7Q/viewform?usp=sharing&ouid=108982467493638405621) 适合将来可能想与我们合作的研究人员。*

确保向变革性人工智能的过渡顺利进行需要了解其对人类和社会的影响。目前，现实世界中与人工智能交互的数据集中在少数实验室中。我们认为，如果能够向研究人员、政策制定者和公众广泛提供更多数据，那就太好了。

实验室外的研究人员有两种选择。他们可以借鉴实验室发布的分析，这些分析反映了真实的使用情况，但通常回答实验室的问题，而不是他们自己的问题。或者他们可以使用公共数据集，他们可以随心所欲地研究这些数据集，但倾向于更随意的使用，并且可能无法反映大多数人实际如何使用人工智能。对于人工智能实际如何使用的独立研究来说，这两者都不够。

今年春天，我们试行了一项计划，其中三个外部研究机构通过以下方式设计并运行了自己的关于Claude使用数据的研究： [人择洞察](https://www.anthropic.com/research/clio) （以前称为“Clio”），我们自己的团队使用的隐私保护工具来分析数百万个 Claude 对话的使用模式。我们希望将来扩大该计划，因此我们还对与第三方研究人员共享的所有数据进行了额外的隐私审核，以验证我们的隐私保护是否得到落实（请参阅 [附录](https://assets.claude.com/37b4cdc86d875d5bdfa7667782a2a7a4fecf1740.pdf)).

我们相信，这是外部研究人员首次对人工智能公司自己的使用数据进行公开独立研究。下面，我们讨论外部团队的发现、我们在试点过程中学到的东西，以及我们在决定如何更广泛地扩展该计划时正在权衡的内容。我们也公开发布 [每个项目的汇总数据](https://huggingface.co/datasets/Anthropic/enabling-independent-research).

## 研究人员了解到什么

我们与三个研究小组合作： [社交和语言技术 (SALT) 实验室](https://cs.stanford.edu/~diyiy/group.html) 在斯坦福大学， [人类信息处理实验室](https://humaninformationprocessing.com/) 在牛津大学，以及 [米特](https://metr.org/)，一个评估前沿人工智能模型的非营利组织。每个小组都制定了自己的研究问题，并使用 Anthropic Insights 对 2026 年 4 月至 5 月期间约 250,000 个 Claude.ai 或 Claude Code 对话进行隐私保护分析。

我们希望我们的外部合作伙伴拥有尽可能多的独立性，因此我们的合同审查权仅限于用户隐私、可能帮助人们违反我们的使用政策的信息、Anthropic 的机密信息和研究准确性。否则，Anthropic 对研究结果的内容没有发言权，研究人员可以自由发表他们的结果，即使这会给 Anthropic 带来不便。以下是一些早期结果。我们对这些方向感到兴奋，也对数据公开后其他人会发现什么感到兴奋。

的 **社交和语言技术实验室** 研究人类如何与人工智能合作。他们研究了人们为人工智能带来哪些类型的工作、人类在完成这项工作时保留哪些角色，以及人类与人工智能的协作在哪里出现问题。他们发现：

- **人们为人工智能带来的高风险工作超出了预期。** 之前的研究表明，人们大多将低责任任务委托给人工智能，而将后果性任务（即影响他人或难以撤销的工作）留给自己。但 SALT 实验室发现，超过一半的Claude对话涉及人们将相应的任务委托给人工智能。人们在寻求专业指导时，最有可能给Claude带来重要的工作，特别是在法律或财务问题上。
- **人们与Claude合作时通常会指导和监督工作。** 在近四分之三的对话中，人们在Claude协助下设定方向，他们通常会调整其输出而不是逐字使用它。但即使在指导Claude获得他们想要的成果时，人们对Claude成果的理解和学习程度也各不相同。
- **人们在与人工智能合作时遇到摩擦是很常见的。** 然而，这种摩擦往往是富有成效的。人们投入的时间和精力来了解Claude如何尝试一项任务，找出请求不清楚或被误解的地方，并迭代他们的方向，从而带来更好的结果——它促使人们澄清他们的意图，完善输出，或继续解决问题。

阅读他们的完整文章 [这里](https://www.alphaxiv.org/abs/2608.human-ai-collaboration-at-scalev1).

的 **人类信息处理实验室** 正在研究人们在使用Claude时的感受以及这与Claude的行为有何关系。他们的早期结果表明：

- **人们在使用人工智能时的感受与人工智能的行为方式有关。** 研究人员发现，人类和人工智能的行为模式在对话中同时出现：Claude的热情与人们的积极性相伴。Claude的拒绝或不同意与人们的反对并驾齐驱。Claude的古怪与人们变得更加理智地参与在一起。而克洛德只是简单地和人们一起帮忙，看起来很满意。
- **人们使用人工智能时的体验看起来很像在网络的其他部分。** 研究人员发现，Claude对话中的专注、沮丧和享受等状态模式与一项针对日常互联网浏览的单独研究中的模式非常相似，这表明人们在与人工智能和其他数字活动进行互动的方式上有相似之处。

他们仍在完成他们的写作。当它公开时，我们将在此处添加一个链接。

**米特** 正在评估编码代理在现实世界中的生产力提升，以及生产力的提高如何在模型代之间发生变化。他们对克劳德·代码对话的分析仍在进行中，但早期结果表明：

- **功能更强大的模型可以为用户节省更多时间。** METR 将Claude对没有人工智能的情况下任务需要多长时间的猜测与使用不同的Claude模型实际需要多长时间进行了比较。他们的初步研究结果表明，较旧的模型相比，新模型的速度显着提高。METR 计划随着分析的进展分享更多信息。
- **人工智能可以很好地估计所花费的时间。** 由于分析依赖于 Claude 判断任务需要多长时间，METR 将这些判断与之前开发人员研究中已知的完成时间进行了比较。Claude的估计与开发人员实际花费的时间相关。
- **下一步：衡量人工智能对研究的加速程度。** METR 正在继续调查他们的研究如何能够深入了解人工智能在多大程度上加快了研究人员的工作速度，这可能会变得越来越重要，因为 [人工智能更多地承担自身的发展](https://www.anthropic.com/institute/recursive-self-improvement).

他们仍在完成他们的写作。当它公开时，我们将在此处添加一个链接。

## 我们团队学到了什么

共享使用数据在人工智能中很大程度上是前所未有的，因此这个试点既是运行此类程序的实验，也是以保护隐私的方式支持第三方研究的一种方式。保护用户的隐私和研究人员的独立性都是至关重要的，我们做到了这两点。Anthropic Insights 就是为此而设计的——研究人员从未访问过原始对话，仅在与我们的内部工作相同的法律和隐私审查之后汇总输出。然而，所有这些都使得试点速度慢于人工智能实验室的正常研究速度和资源密集型运行。这两个因素都对有效扩展规模提出了挑战。有关我们如何运行此试点的更多详细信息，请参阅 [附录](https://assets.claude.com/37b4cdc86d875d5bdfa7667782a2a7a4fecf1740.pdf)。下面我们讨论我们学到的东西以及我们如何应对出现的挑战。

**从不同的角度来探讨同一个问题是有价值的。** 我们的一些合作伙伴的研究问题与内部正在进行的工作重叠。例如，METR的建议与我们的经济学研究类似“[代理编码和专业知识的持续回报](https://www.anthropic.com/research/claude-code-expertise)”。我们发现这种重叠很有价值：它使外部研究人员有机会检查类似的数据并得出自己的结论。随着他们的研究继续进行，我们将关注这些是否与我们的一致。我们还将 METR 与我们的经济团队联系起来，发现这种联系改善了两个研究团队的工作。

**内部有效的研究方法需要适应外部合作伙伴。** 使用人类洞察时，研究人员会写一个问题，例如“这个人需要什么类型的指导？”Claude对书房中的每一次对话都进行了回答。然后将答案汇总为类别；研究人员只能看到最终类别以及属于每个类别的对话百分比。因为我们依赖 Claude 的判断，所以该工具对问题的措辞很敏感；措辞不当的人可能会将对话归为歪曲事实的类别。由于没有人能够读取底层对话，因此这些错误很难被发现。

在内部，我们通过在几周内多次迭代这些问题来解决这个问题。外部合作伙伴无法做到这一点，因为在共享每个数据集之前重复进行隐私审查将使研究变得不可行。相反，我们让他们在 WildChat 上测试他们的问题，这是一个人类与人工智能对话的公共数据集，他们可以在其中根据底层对话本身检查答案。但与 Claude 流量不同，WildChat 偏向于随意和创造性的使用，因此一些在 WildChat 上表现良好的问题一旦应用于实际的 Claude 对话，就会产生误导性的类别。我们通过提供有关如何解释 Anthropic Insight 输出的指导来解决这个问题（请参阅 [附录](https://assets.claude.com/37b4cdc86d875d5bdfa7667782a2a7a4fecf1740.pdf)）。展望未来，我们正在探索外部研究人员如何提前更有效地提出他们的问题和类别。

**在不启用滥用的情况下保持滥用的透明度。** 我们合作伙伴的人类洞察输出中的某些类别违反了我们的可接受使用政策或服务条款，例如寻求有关禁止活动指导的一类人。我们认为公众应该了解我们平台的滥用行为，因此我们分享了大部分违规行为。例外是描述的类别 *如何* 用户绕过了我们的保护措施，而不是 *什么* 他们尝试过。每项研究中只有不到 5% 的类别和对话受到影响，在每种情况下，我们都会告诉研究人员我们更改或删除了哪些集群以及原因。作为标准做法，当 Anthropic Insights 发现此类违规行为时，我们会与保障团队共享汇总数据以供他们审核。这也是我们与外部研究人员合作向前推进的一个重要过程。

## 展望未来

对于人工智能公司来说，了解人工智能对社会的影响是一项艰巨的任务。真正的监督需要外部研究人员对现实世界的使用数据提出自己的问题，并独立发布他们的发现。

这个试点是一个实验：外部研究人员能否在我们的平台上进行独立研究而不损害我们用户的隐私？这项工作比我们预期的更具挑战性，我们学到了很多教训，但到目前为止，答案似乎是肯定的。我们的合作伙伴进行了我们自己设计时不会想到的研究，每个人都告诉我们一些关于人工智能对现实世界影响的新知识。这是充满希望的第一步，但还有更多工作要做。

下一步是我们确定是否可以扩展该计划，在考虑到上述限制的情况下我们可以支持哪些类型的研究，以及我们可以同时运行多少个研究。我们正在慢慢开始确保隐私、安全和研究质量。我们想要衡量兴趣并了解研究人员想要研究什么。如果您是一名研究人员，并且访问 Anthropic Insights 可以让您从事目前无法完成的工作，请填写 [这个表格](https://docs.google.com/forms/d/1PyyC-GU4Jra2WoXWcJjuFXZhM-lRxeBNnlh1tJv_2Jg/edit).
